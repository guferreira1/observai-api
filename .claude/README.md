# Codex workspace

This folder documents how AI assistants should work in ObservAI API.

## Folders

- `rules/`: project conventions and constraints.
- `agents/`: specialist roles for architecture, Go, reliability and analysis.
- `skills/`: reusable playbooks for common activities.
- `hooks/`: checklists for starting and finishing a work session.
- `tasks/`: templates for planning and handoff.
- `memory.md`: concise project session notes.

## Reading order

Start with `AGENTS.md`, then this file, then the relevant files under `.codex/`.

End each relevant session by adding a short note to `.codex/memory.md`.
