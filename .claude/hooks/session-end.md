# Session end checklist

Use this checklist before finishing work.

## Checklist

- Review the changed files.
- Run relevant tests when possible.
- Run `gofmt` when Go files changed.
- Confirm no confidential values were added.
- Confirm core packages do not depend on adapters.
- Document pending items.
- Add a short entry to `.codex/memory.md`.
- Summarize what changed for owner review.
