# Session start checklist

Use this checklist before starting work.

## Checklist

- Read `AGENTS.md`.
- Read `.codex/README.md`.
- Read `.codex/memory.md`.
- Read the rules related to the task.
- Select the most relevant specialized agent profile.
- Confirm the active branch is not `main`.
- Understand the expected outcome before changing files.
- Identify which tests should validate the change.
